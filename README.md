# K1 Daily — 개인 시간대별 체크리스트 실행력 서비스 (MVP v0.1.0)

개인이 직접 항목·시간을 정하고, 정해진 시간에 웹 푸시 알림을 받아 **알림에서 바로 [완료]** 를 누르는 서비스.
중앙에는 사람이 없고, **룰 기반으로 준수율과 응원 메시지**를 보여 준다. 피드백 화면 하단에 공지·홍보·광고 영역 1개.

- 사이트: https://kangsh8880.github.io/k1-daily/
- DB: Supabase (Daily Check List 프로젝트 공유, 모든 객체 `hc_` 접두어로 분리)

## 화면
| 파일 | 내용 |
|---|---|
| index.html | 로그인 (이메일 인증 코드 / 메일 링크, 비밀번호 없음) |
| today.html | 오늘 체크 (시간대별 목록, 탭하면 완료, 준수율, 응원 메시지, 하단 배너, 첫 방문 시 추천 세트) |
| items.html | 항목 추가·수정·일시중지·삭제, 추천 세트 불러오기 |
| report.html | 준수율 KPI(오늘·7일·30일·연속 달성), 준수율 추이, 분류별·항목별 준수율 |
| settings.html | 이름·시간대, 알림 켜기/테스트/끄기, 홈 화면 추가 안내, 테마, 로그아웃 |
| admin.html | 관리자: 응원 메시지 / 하단 배너 / 룰 기준 (개인 데이터는 관리자도 볼 수 없음) |

## 구조
```
css/style.css            공통 디자인 (파스텔, 글자 크기 변수)
js/config.js             Supabase 주소·공개키·VAPID 공개키
js/i18n.js               다국어 구조 (1단계 한국어)
js/common.js             클라이언트·인증 가드·내비·토스트·모달·배너·피드백
js/push.js               웹푸시 구독/해제/테스트
js/<화면>.js             화면별 로직
sw.js                    서비스워커 (푸시 수신, [완료]/[30분 후] 버튼 처리)
sql/001_schema.sql       테이블·함수·RLS·권한
sql/002_seed.sql         룰·응원 메시지·배너·추천 세트·관리자
sql/003_cron.template.sql 매분 알림 예약 작업 (비밀값은 별도 파일)
supabase/functions/k1-daily-push/index.ts  푸시 발송 Edge Function
```

## 설계 원칙
- 회차(hc_occ)는 날짜별로 확정 생성 → 항목 수정은 **다음 회차부터**, 삭제해도 **지난 기록 보존**
- 준수율 = 완료 ÷ 시간이 지난 회차(미리 완료 포함), 단일 산식 `hc_day_stats` 를 모든 화면·룰이 공유
- %는 소수 1자리, 건수·일수는 정수 / 추이 차트 제목 = KPI명 + " 추이" / 기간 필터는 추이 차트에만
- 광고·홍보는 피드백 화면 하단에만, 푸시·메일에는 넣지 않음 / 건강 항목은 광고 타기팅에 쓰지 않음
- 비밀값(VAPID 개인키, CRON_SECRET)은 저장소에 두지 않음
